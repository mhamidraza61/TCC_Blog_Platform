# Client (React Frontend)

This folder is reserved for the React frontend, which gets built starting
Week 3 (Core CRUD UI) and finished in Week 4 (Search, Images & Deployment).

For now this is just a placeholder so the repo has the correct
`client/` + `server/` structure required by Week 1.

When you're ready to start it (Week 3), run from inside `client/`:

```
npm create vite@latest . -- --template react
npm install
npm install axios react-router-dom react-hook-form zod
```
